# Pebble Metro WP8
Retro Windows Phone 8 Metro style watchface.
For Pebble Time 2, Time and Time Steel (Emery & Basalt).<br>
Current version: 1.6.0  |  https://apps.repebble.com/metro-wp8_b406d87ebcd144ff9cd278a3

## NEW! Selectable Live Tiles.
Select any of below Tile types for slots 3, 5, 6 and 7. Available Tiles:
- Air quality
- Daily steps
- Daily sleep total
- Moon phase
- Rain forecast
- Heart rate (Emery only of course; option hidden for Basalt)
- Calories burned today
- Sunrise/sunset
- Week numbers (😎 personal need)
- Windspeed and direction
- UV Index
- UV/Smog (bare UV number & Ozone (O3) reading)
- Battery (watch AND phone! (shows CHR when phone charging))

And more to come.

## Features
- Clock tile (follows watch settings for 12/24h) and weekday/date tile.
- Air Quality Index tile, location based Weather tile (weather-code icon, current temp and H/L temps)
- Light and Dark theme
- 16 Accent colours
- 2 Random tiles flip once each, every time you flick your wrist (or when the light comes on)
- Preview of your settings in the settings screen (see phone screens below)
