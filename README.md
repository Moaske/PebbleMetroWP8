# Pebble Metro WP8
Retro Windows Phone 8 Metro style watchface.
For Pebble Time 2 only (Emery / Obelix).

## Features
- Clock (follows watch settings for 12/24h) tile and weekday/date tile.
- Air Quality Index tile, location based Weather tile (weather-code icon, current temp and H/L temps)
- Daily Steps tile, Daily Sleep total tile, Battery status tile
- Light and Dark theme
- 16 Accent colours
- 2 Random tiles flip once each, every time you flick your wrist (or when the light comes on)
- Preview of your settings in the settings screen
