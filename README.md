# Pebble Metro WP8
Retro Windows Phone 8 Metro style watchface.
For Pebble Time 2, Time and Time Steel (Emery & Basalt).<br>
Current version: 1.5.0

## NEW! Selectable Live Tiles. Available Tiles:
- Air quality
- Daily steps
- Daily sleep total
- Moon phase
- Rain forecast
- Heart rate
- Calories birned today
- Sunrise/sunset
- Week numbers (😎 personal need)
And more to come.

## Features
- Clock tile (follows watch settings for 12/24h) and weekday/date tile.
- Air Quality Index tile, location based Weather tile (weather-code icon, current temp and H/L temps)
- Battery status tile (Pebble AND Phone! Will also show CHRG for Phone)
- Light and Dark theme
- 16 Accent colours
- 2 Random tiles flip once each, every time you flick your wrist (or when the light comes on)
- Preview of your settings in the settings screen (see phone screens below)
